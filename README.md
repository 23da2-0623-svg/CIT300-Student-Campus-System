## 📌 Project Overview
This project is a Java console-based application designed to manage university student records and visualize campus route networks. It integrates core linear and non-linear data structures to handle efficient data searching, history tracking, queue-based request processing, and graph-based network operations.

## ⚙️ Implemented Data Structures & Features

1. **Student Record Management (Linked List)**
   - Add, Update, Delete, Search, and Display Student Records (ID, Name, Programme, Marks).

2. **Action History & Undo System (Stack)**
   - Tracks recent user actions and deleted records to support history and undo functionalities.

3. **Service Request System (Queue)**
   - Enqueues incoming student service requests and processes them in First-In-First-Out (FIFO) order.

4. **Hierarchical Indexing & Fast Lookup (BST / AVL Tree)**
   - Organizes and displays student records sorted by Student ID for fast binary searching.

5. **Direct ID Lookup (Hashing)**
   - Supports constant-time searching using a Hash Table with collision handling.

6. **Campus Route Network (Graph - Adjacency List/Matrix)**
   - Represents campus locations as vertices and roads/paths as edges.
   - Operations: Add/Remove locations, Add/Remove connections, and Display campus graph.
   - Traversal: Graph exploration using **Breadth-First Search (BFS)** or **Depth-First Search (DFS)**.
